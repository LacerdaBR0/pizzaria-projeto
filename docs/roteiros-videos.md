# 🎬 Roteiros dos vídeos

Cada vídeo: **2–5 min**, tela gravada, mostrando a funcionalidade do sprint de ponta a
ponta. Não precisa de produção — só clareza. Sugestão de estrutura para todos:
1. Dizer qual é a funcionalidade do sprint (10s)
2. Demonstrar funcionando
3. Mostrar rapidamente o dado no banco / no código quando fizer sentido

---

## AC1 — Cardápio (CRUD)
- Abrir a listagem do cardápio (vazia)
- Criar uma pizza (nome, categoria, tamanho, preço)
- Editar o preço dela
- Excluir um item
- Mostrar a tabela no SQL Server com o registro salvo

## AC2 — Monte sua pizza + carrinho
- Montar uma pizza **meio-a-meio** com dois sabores de preços diferentes
- Destacar que o preço usa o **sabor mais caro**
- Adicionar borda/adicional e ver o subtotal mudar
- Jogar no carrinho e mostrar o carrinho com o item

## AC3 — Pedido + login
- Registrar um usuário novo
- Fazer login
- Montar um pedido, informar endereço e pagamento
- Finalizar o pedido
- Mostrar o pedido salvo (histórico + banco)
- (Opcional) mostrar um segundo usuário sem enxergar os pedidos do primeiro

## Final — Painel da pizzaria + relatório
- Entrar como atendente/admin
- Ver o pedido feito na AC3 chegando como "Recebido"
- Avançar o status até "Entregue"
- Abrir o dashboard: pizzas mais vendidas + faturamento do dia
- Exportar o relatório (PDF/CSV)
